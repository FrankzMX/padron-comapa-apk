# Padrón COMAPA: app para capturistas

Aquí solo se publica la app Android (APK) del padrón de beneficiarios de pipas de COMAPA Victoria. El código no está en este repositorio.

## Descargar
Entra a **[Releases](../../releases/latest)** desde el teléfono y descarga el archivo `padron-comapa-vX.Y.Z.apk` de la versión más reciente.

## Instalar
1. Abre el APK descargado.
2. Si el teléfono lo pide, permite **Instalar apps desconocidas** para el navegador o la app de Archivos.
3. Abre **Padrón COMAPA** e inicia sesión **con internet** con el usuario y la contraseña que te dio tu supervisor.

Para actualizar, descarga la versión nueva e instálala encima. **No desinstales la app** si tiene registros pendientes de subir: se perderían.

La app no sirve sin un usuario dado de alta por COMAPA. Si no tienes uno, habla con tu supervisor.
